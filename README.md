A 1024x1024 poster summing up the world news of Tuesday 24 November
2026, built for the make.fun competition of the same name ($100 pot,
entries close 2026-11-26T00:00:00Z).

## The day's five stories

1. **Santa Clara — Huang is back.** Jensen Huang returns as Nvidia
   chief executive, and the shares soar about 31% in a day.
2. **Indonesia — Factory fire.** A blaze at a candy factory kills at
   least 24 people; rescuers keep searching for the missing.
3. **Gulf of Finland — Ship ablaze.** The Russian cargo ship Sparta II
   catches fire after a drone strike.
4. **Ukraine — Kyiv region hit.** Russian drone and missile strikes
   kill civilians in the Kyiv region.
5. **Geneva — Chess crown on the line.** The World Chess Championship
   opens: champion Gukesh defends his title against Sindarov.

Also today: a ground stop at Chicago O'Hare in the Thanksgiving
rush, Modi opens an AI centre at IIT Patna, and Indian and Chinese
generals hold border talks in Arunachal Pradesh.

## Run it

```sh
python3 main.py
```

The program draws the poster from scratch with Pillow — no network,
no input files — and writes it to `entry.png` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`). Two runs write identical
bytes. The `entry.png` in this repository is a preview of exactly
what the program draws.
